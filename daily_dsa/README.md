# Daily Data Structures & Algorithms

This folder is for consistent GitHub-visible DSA practice.

## Format

Each solution should include:

- A short problem statement
- Time and space complexity
- Clean Python implementation
- A few runnable tests

## Roadmap

1. Arrays and hash maps
2. Two pointers and sliding window
3. Stack, queue, and monotonic structures
4. Linked lists
5. Trees and binary search trees
6. Heaps and priority queues
7. Graph traversal
8. Dynamic programming
9. Greedy algorithms
10. Backtracking
